- Passwords did not match at Ubuntu setup. Linux hides typing, so retype carefully.

- GitHub HTTPS password auth failed. Fix: authenticated via gh auth setup-git.
- Using 'cat' on a directory name fails because cat is for reading text files, not folders. Fix: use 'ls'.
